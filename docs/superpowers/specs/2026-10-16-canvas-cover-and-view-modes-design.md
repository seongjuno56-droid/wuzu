# 표지 캔버스 꾸미기 · 스토리형/스크롤형 보기 설계 (3단계)

2단계(`2026-10-15-wedding-invitation-editor-design.md`)의 결혼식 초대장 제작 위에 얹는다.
서버 없음 — 저장은 계속 mock 서비스(AsyncStorage). 미디어 압축·공유 링크는 서버 단계에서 보완한다.

## 0. 목표와 결정 사항
- 목표: 인스타그램 스토리처럼 슬라이드를 직접 꾸미는 자유도를 주되, 꾸미기 부담스러운 사용자는 지금의 폼 입력 방식으로 끝낼 수 있게 한다.
- 결정(사용자 확정)
  - 하객 보기 형태는 **스토리형**(e-book처럼 한 장씩 넘김)과 **스크롤형**(현재 방식) 두 가지. **제작자가 고른다.**
  - 선택 위치: 템플릿 미리보기. 제작 중에도 바꿀 수 있다.
  - 편집 방식은 **형식(폼)으로 시작하고, 슬라이드마다 "직접 꾸미기"로 캔버스 전환**한다(섹션별로 형식/자유를 섞어 쓸 수 있음).
  - 캔버스 1차 범위는 **표지만**. 다른 슬라이드는 형식 고정(버튼 없음).
  - 편집 중 슬라이드 선택은 **하단 독바**에서 한다(기존 섹션 탭바 대체).
  - 캔버스 요소: 텍스트, 연결 텍스트, 사진, 스티커, GIF, 동영상, 그리기 펜, 붙여넣기(외부에서 복사한 이미지·텍스트), 배경.
  - 하객 보기는 웹으로 공유되므로 **반응형**(폴드 펼침·태블릿·PC 포함) 필수.
- 구현 방식: **RN 화면 요소 + 제스처**(Skia·웹뷰 캔버스는 쓰지 않음). 텍스트가 실제 텍스트로 남고 Expo Go·웹 모두 동작한다.
  - 추가 패키지(`npx expo install`): `react-native-gesture-handler`, `react-native-reanimated`(+`react-native-worklets`, SDK 문서 확인), `react-native-svg`, `expo-video`, `expo-image`. 모두 Expo Go 포함 모듈.

## 1. 흐름
### 1-1. 템플릿 미리보기 (`create/[theme]/[templateId]`)
- 상단에 보기 전환 칩 [스토리형][스크롤형] — 같은 예시 데이터를 두 형태로 보여준다(기본: 스토리형).
- [이 템플릿으로 만들기] → 스타일 선택 시트: 두 카드(작은 예시 그림 + 한 줄 설명), 미리보기에서 보던 형태가 기본 선택. [시작하기] → Step3.
  - 스토리형: "한 장씩 넘겨 보는 초대장"
  - 스크롤형: "아래로 이어서 보는 초대장"

### 1-2. Step3·Step4 — 변경 없음

### 1-3. Step5 편집 (`create/editor/compose`)
- 헤더: ← 초대장 설정 / 임시저장 / 최종저장 (기존과 동일) + 설정(⚙) 시트에 "보기 형태" [스토리형][스크롤형].
- 가운데: 현재 슬라이드 하나를 9:16으로 크게(화면에 맞춰 축소). 슬라이드를 좌우로 밀어도 이동.
- 하단 독바: 슬라이드 썸네일을 페이지 순서대로 가로 스크롤(표지·인사말·…·엔딩). 선택 슬라이드는 테두리 강조, 미완료는 빨간 점. 기본정보·BGM처럼 페이지가 없는 섹션은 독바 맨 끝 "정보" 칩 묶음([기본정보][BGM])으로 연다.
  - 스크롤형 초대장도 편집은 같은 슬라이드 방식(편집 화면은 형태와 무관). 형태 차이는 미리보기 버튼(👁)으로 확인.
- 형식 슬라이드: 슬라이드를 누르거나 [편집] 버튼 → 기존 바텀시트 폼. 표지 형식 편집은 기본정보 시트를 연다.
- 표지에는 [직접 꾸미기] 버튼.
  - 누르면 템플릿 배치가 그대로 편집 가능한 요소로 바뀌고 캔버스 모드로 들어간다.
  - 캔버스 모드: 상단 툴바 [텍스트][사진][스티커][GIF][동영상][펜][붙여넣기][배경] + [되돌리기][다시하기][완료]. 독바는 숨긴다(완료 시 복귀).
  - 요소 선택 시: 선택 테두리 + 하단 속성 바(텍스트: 글꼴·색·크기·정렬·수정 / 사진: 교체·모양 / 공통: 앞으로·뒤로·복제·삭제).
  - 캔버스 상태의 표지에는 [다시 꾸미기]와 더보기 메뉴 [템플릿 원래대로](확인 모달: "꾸민 내용이 모두 사라집니다.").
- 이탈 경고·저장 규칙은 기존과 동일. 표지 캔버스는 완료 검사 대상이 아니다(기본정보 완료가 표지 완료).

## 2. 캔버스 상세
### 2-1. 공통 조작
- 한 손가락 끌기: 이동 / 두 손가락: 크기·회전 동시 / 탭: 선택 / 빈 곳 탭: 선택 해제 / 텍스트 더블탭: 수정.
- 가이드선: 요소 중심이 슬라이드 가로·세로 중앙에 가까우면(슬라이드 폭 2% 이내) 붙고 선을 보여준다. 회전은 0·90·180·270° 근처(5°)에서 붙는다.
- 요소는 슬라이드 밖으로 일부 나갈 수 있지만 중심은 슬라이드 안으로 제한한다.
- 되돌리기/다시하기: 조작 단위(끌기 한 번 = 1단계) 최대 50단계, 편집 중 메모리에만 보관.
- 웹: Delete/Backspace 삭제, Ctrl+Z/Ctrl+Shift+Z, Ctrl+V 붙여넣기.

### 2-2. 요소 종류
| 종류 | 내용 |
|---|---|
| 텍스트 | 최대 100자, 줄바꿈. 글꼴: 템플릿이 정한 3~4종(Pretendard·Hahmlet 등 번들 폰트) / 색: 템플릿 팔레트 8색 / 크기: 슬라이드 폭 대비 비율 / 정렬 좌·중·우 |
| 연결 텍스트 | `bind` 값: 신랑 이름, 신부 이름, "신랑 & 신부", 예식 날짜, 예식 시간, 예식장명. 글자는 폼 값으로 그리고, 캔버스에서는 위치·스타일만 바꾼다. 수정 시 "기본정보에서 바꿀 수 있어요" 안내 + [기본정보 열기] |
| 사진 | 앨범에서 1장 / 모양: 사각·둥근 사각·원 / 교체 |
| 스티커 | Fluent 3D 아이콘(`assets/icons`) + 장식 목록 |
| GIF | 앨범·파일·붙여넣기. 움직이는 그대로 표시 |
| 동영상 | 앨범에서 1개. 소리 없이 자동 반복 재생 |
| 그리기 | 펜 모드에서 굵기 3단계·팔레트 색·지우개(선 단위 삭제). 한 번 그은 선 = 요소 1개(이동·삭제 가능) |
| 배경 | 템플릿 기본 / 단색(팔레트) / 사진 1장(채우기) |

### 2-3. 붙여넣기
- [붙여넣기] 버튼: 클립보드에 이미지가 있으면 사진(또는 GIF) 요소, 없고 텍스트가 있으면 텍스트 요소(100자 초과는 잘라냄), 둘 다 없으면 "붙여넣을 내용이 없어요" 안내.
- 앱: `expo-clipboard`(이미지·문자열). iOS는 운영체제 "붙여넣기 허용" 확인창이 뜰 수 있고, 거부하면 안내만 한다.
- 웹: Ctrl+V는 `paste` 이벤트의 파일(GIF 포함)·텍스트를 받는다. 버튼은 `navigator.clipboard.read` 사용, 권한 거부·미지원 시 "Ctrl+V로 붙여넣어 주세요" 안내.
- 동영상은 클립보드로 받지 않는다(앨범에서 선택).

### 2-4. 템플릿 원본 = 캔버스 프리셋
- 각 템플릿의 표지는 캔버스 문서 프리셋(`coverPreset(templateId)`)으로 정의한다. 형식 모드 표지도 이 프리셋을 같은 캔버스 렌더러로 그린다(조작만 막음).
- [직접 꾸미기] = 프리셋 복사본으로 시작 → 형식/캔버스 전환 시 모습이 바뀌지 않는다.
- [템플릿 원래대로] = 표지 디자인을 형식 모드로 되돌림(캔버스 문서 삭제).

## 3. 데이터
```ts
type ViewMode = 'story' | 'scroll';

interface Invitation {
  // 기존 필드 +
  viewMode: ViewMode;                                   // 기본 'story'
  design: Partial<Record<PageKey, SlideDesign>>;       // 없으면 형식
}

type SlideDesign = { mode: 'form' } | { mode: 'canvas'; canvas: CanvasDoc };

interface CanvasDoc {
  background: { kind: 'template' } | { kind: 'color'; color: string } | { kind: 'image'; uri: string };
  elements: CanvasElement[];   // 배열 순서 = 쌓는 순서(뒤 → 앞)
}

interface ElementBase {
  id: string;
  x: number; y: number;        // 중심 좌표, 슬라이드 폭·높이 대비 0~1
  w: number;                   // 폭, 슬라이드 폭 대비 (높이는 종류별 비율로 계산)
  rotation: number;            // 도
}
type CanvasElement = ElementBase & (
  | { kind: 'text'; text: string; font: FontKey; color: string; size: number; align: 'left' | 'center' | 'right' }
  | { kind: 'bound'; bind: BindKey; font: FontKey; color: string; size: number; align: 'left' | 'center' | 'right' }
  | { kind: 'image'; uri: string; aspect: number; shape: 'rect' | 'rounded' | 'circle' }
  | { kind: 'gif'; uri: string; aspect: number }
  | { kind: 'video'; uri: string; aspect: number; durationMs: number }
  | { kind: 'sticker'; icon: string; aspect: number }
  | { kind: 'stroke'; points: number[]; color: string; width: number; aspect: number } // points: 상자 대비 0~1 [x0,y0,x1,y1…]
);
type BindKey = 'groomName' | 'brideName' | 'coupleNames' | 'date' | 'time' | 'venue';
```
- `size`(글자 크기)와 `stroke.width`도 슬라이드 폭 대비 비율 → 어떤 화면 폭에서도 같은 모습.
- 연결 텍스트는 그릴 때 `resolveBind(bind, content)`로 글자를 만든다(이름이 비면 "신랑"/"신부" 같은 안내 글자를 흐리게).
- 기존 저장본(viewMode·design 없음)은 불러올 때 `viewMode: 'story'`, `design: {}`로 채운다.
- 편집 스토어: `setViewMode`, `startCanvas(page)`, `resetDesign(page)`, `applyCanvas(page, doc)` + 캔버스 편집용 별도 스토어(선택 요소, 되돌리기 기록)를 둔다. 캔버스 [완료] 시 편집 스토어에 반영(dirty).

## 4. 하객 보기 (공유 웹 + 앱 내 보기)
### 4-1. 스토리형
- 9:16 슬라이드를 한 장씩. 좌우 밀기 또는 화면 좌·우 1/3 탭으로 이동, 상단에 페이지 막대(인스타 스토리형). 자동 넘김 없음.
- 형식 슬라이드는 9:16 안에 맞춰 그린다. 내용이 넘치는 슬라이드(방명록 목록·계좌·그리드 갤러리)는 슬라이드 안에서 세로 스크롤.
- 방명록 작성·계좌 복사·지도 링크·BGM 버튼은 그대로 동작. 슬라이드 안 스크롤·버튼 위에서는 넘김 탭이 동작하지 않는다.

### 4-2. 스크롤형
- 표지는 9:16 캔버스(형식이면 프리셋), 이후 섹션은 현재처럼 세로로 이어 붙인다.

### 4-3. 반응형 (폴드·태블릿·PC)
- 화면 크기는 `useWindowDimensions`로 실시간 반영한다 — 폴드를 접고 펴는 순간 다시 배치.
- 스토리형: 슬라이드는 화면에 "맞춤"(가로·세로 중 작은 쪽 기준) 후 가운데. 남는 여백은 템플릿 배경색(또는 표지 배경 흐림). 폭 600px 이상(폴드 펼침·태블릿·PC)에서는 좌우 화살표 버튼을 보이고, 키보드 ←/→ 지원.
- 스크롤형: 본문 칼럼 최대 폭 480px 가운데 정렬, 표지도 그 폭의 9:16. 600px 이상에서는 양옆 여백에 배경색.
- 기준 폭: 360(일반 폰), 412(큰 폰), 약 600×700(폴드 펼침, 정사각형에 가까움), 768+(태블릿), 1280+(PC).
- 공유 링크 발급(실제 URL)은 서버 단계. 이번에는 웹 `/invite/[id]`가 위 규칙으로 보이게 만든다.

## 5. 제한과 오류 처리
| 항목 | 규칙 | 안내 |
|---|---|---|
| 캔버스 사진 | jpg·jpeg·png, 업로드 즉시 압축(긴 변 1280px, 기존 규칙과 동일). 투명 PNG는 PNG 유지 | 확장자 오류: "허용되지 않은 확장자입니다." |
| GIF | 10MB 이하, 슬라이드당 3개. 압축하지 않음(움직임 보존) | "GIF는 10MB 이하로 올려주세요." / "GIF는 3개까지 넣을 수 있어요." |
| 동영상 | 15초·30MB 이하, 슬라이드당 1개, mp4·mov | "15초 이하 영상만 올릴 수 있어요." / "30MB 이하로 올려주세요." / "영상은 1개까지 넣을 수 있어요." |
| 요소 수 | 슬라이드당 30개(선 포함) | "요소는 30개까지 넣을 수 있어요." |
| 붙여넣기 | 비었음·권한 거부·지원 안 함 | 2-3 참고 |
| 미디어 로드 실패 | 회색 상자 + 깨진 이미지 아이콘, 편집 화면에서는 [교체] | — |
- 웹: 동영상·GIF는 객체 URL로만 보관 → 새로고침하면 사라진다(BGM과 같음, 회색 상자 표시). 앱: 선택한 파일 경로 사용.

## 6. 보완 목록 (이번 범위 밖, 다음 단계 1순위부터)
1. 동영상·GIF 압축 — 업로드 즉시 최대한 압축. Expo Go에는 압축 모듈이 없어 서버 변환(트랜스코딩) 또는 개발용 빌드 + 압축 모듈로 처리.
2. 공유 링크 발급·카카오톡 공유(서버).
3. 캔버스 범위 확장(인사말·엔딩 → 전체).
4. 자동 저장, Step3·4 통합(이전 UX 검토 제안).
5. 애니메이션 효과, 사용자 글꼴.

## 7. 테스트
- 단위(jest): 비율 좌표 ↔ 화면 좌표 변환, 가이드선 붙기, 연결 텍스트 치환, 되돌리기 기록(50단계·다시하기 초기화), 제한 검사(GIF·영상·요소 수), 기존 저장본 보정, [템플릿 원래대로], 프리셋 복사.
- 브라우저 점검(Playwright): 스타일 선택 → 표지 꾸미기(텍스트 추가·수정, 이동·크기·회전, 펜, 붙여넣기, 배경, 되돌리기) → 저장 → 스토리형/스크롤형 보기, 화면 폭 360·412·600×700·1280에서 확인.
- 완료 전 `npx tsc --noEmit`, `npx expo lint`, jest, `npx expo-doctor`.
