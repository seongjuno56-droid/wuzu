# 돌잔치·기업 행사·모임 초대장 설계

작성일: 2026-10-22
상태: 승인됨 (1~4단계 구현 완료)

## 1. 목표

지금은 결혼식 초대장만 만들 수 있다. 돌잔치·기업 행사·모임도 결혼식과 같은 수준(템플릿 미리보기 → 입력항목 선택 → 정보 입력 → 저장·활성화 → 하객 화면)으로 만들 수 있게 한다.

- 결혼식 화면과 데이터는 바뀌지 않는다. 이미 만든 결혼식 초대장은 그대로 열린다.
- 진행 순서: **돌잔치 → 기업 행사 → 모임**. 설계는 이 문서 하나로, 구현 계획은 테마마다 따로 쓴다(1단계 계획에 공통 구조 포함).

참고 자료
- 돌잔치: 비비드바우스 베이비 샘플(baby.vividvows.co.kr/card/sample-1)과 편집 화면 구조
- 기업·모임: 국내 행사 초대장 서비스(달팽, 개업식초대장, 아이디어스 행사 초대장)와 해외 기업 초대 가이드(Paperless Post, invyt, EventGuru, Blackbird RSVP). 공통 필수는 행사명·일시·장소·초대 문구·문의처, 기업은 참석 회신·드레스코드·프로그램·연사가 덧붙는다.

## 2. 구조: 테마별 구성 정의

테마마다 "섹션 정의"를 둔다. 정보 입력 화면(독바·슬라이드·입력 시트), 입력항목 선택, 하객 화면, 미리보기, 저장 검사는 모두 이 정의를 읽어 동작한다. 결혼식도 같은 정의로 옮긴다(동작은 그대로).

```
ThemeDefinition
  id: 'wedding' | 'dol' | 'corporate' | 'meetup'
  sections: 입력 단위(독바 정보 칩·입력 시트) — 키, 이름, 필수 여부, 입력 폼, 검사 함수
  pages:    하객 화면 장 — 키, 이름, 그리는 부품, 연결된 섹션, 위치(앞 고정·뒤 고정·이동 가능)
  optional: 입력항목 선택에서 켜고 끌 섹션과 기본값
  defaultOrder: 이동 가능한 장의 기본 순서
  createContent(today) / normalize(content) / sample(templateId)
  binds:    [직접 꾸미기] 정보 글자 목록과 값 계산
  templates / palettes
```

- `Invitation.content` 는 테마별 타입(`WeddingContent | DolContent | CorporateContent | MeetupContent`)이고 `themeId` 로 구분한다. 지금의 `InvitationContent` 는 `WeddingContent` 로 이름만 바꾼다.
- `SectionKey`·`PageKey`·`enabled`·`order` 는 테마 정의가 주는 문자열 키로 넓힌다. 결혼식 키 값은 그대로라 저장된 데이터를 옮길 필요가 없다.
- 공통 부품(그대로 재사용): 인사말, 일시·장소(지금 예식 정보 — 달력·D-day·지도), 갤러리, 방명록, 엔딩, BGM, 계좌 목록, 직접 꾸미기, 보기 형태, 색상, 독바 순서 끌기.
- 새 공통 부품: **목록형 입력**(항목 추가·삭제·끌어 순서 바꾸기, 최대 개수) — 성장 이야기·일정표·프로그램·연사·안내사항·보호자가 같이 쓴다.

## 3. 돌잔치

### 기본 정보
- 아이 이름(필수), 부르는 이름(비우면 성을 뺀 이름 — 예: 이시안 → 시안. 두 글자 이하면 이름 그대로), 태어난 날(필수)
- 보호자 1~4명: 관계(직접 입력, 기본 "아빠"·"엄마"), 이름, 계좌(은행·번호, 선택)

### 장(기본 순서)
| 장 | 위치 | 켜고 끄기 | 입력 | 하객 화면 |
|---|---|---|---|---|
| 표지 | 맨 앞 | — | 아이 사진(필수) | "Happy First BIRTHDAY" + 템플릿별 사진 틀 + 이름·날짜·장소·보호자. [직접 꾸미기] 가능 |
| 인사말 | 두 번째 | — | 문구(돌잔치 기본 문구 미리 채움) | 보호자 이름 서명 |
| 아이 프로필 | 이동 | 켬 | 사진, 소개 문구, #해시태그 최대 5개 | "○년 ○월 ○일에 태어난", "○○·○○의 보물"(보호자 이름 자동), 소개, 해시태그 |
| 성장 이야기 | 이동 | 켬 | 항목 최대 6개(사진·날짜·제목·한 줄) | 세로 타임라인 |
| 일시·장소 | 이동 | 늘 켬 | 결혼식 예식 정보와 같은 틀 | "첫 생일까지 ○일" |
| 갤러리 | 이동 | 켬 | 결혼식과 같음 | |
| 방명록 | 이동 | 켬 | 결혼식과 같음 | |
| 계좌 | 이동 | 켬 | 기본 정보의 보호자 계좌 + 안내 문구 | "마음 전하는 곳", 입력한 보호자만 |
| 엔딩 | 맨 끝 | 켬 | 결혼식과 같음 | |
| BGM | (장 아님) | 끔 | 결혼식과 같음 | |

### 성장 이야기 미리 채우기
태어난 날을 처음 넣으면 4개 항목을 채운다(이미 고친 항목은 건드리지 않는다).
1. 태어난 날 — 날짜 = 태어난 날, "작은 울음으로 모든 하루를 바꾼 날"
2. 100일 — 날짜 = 태어난 날 + 99일, "먹고 자고 웃다 보니 어느새 100일"
3. 첫 걸음마 — 날짜 비움(직접 선택), "하루하루가 처음이었어요"
4. 첫 생일 — 날짜 = 행사일(없으면 태어난 날 + 1년), "드디어 저의 첫 생일이에요"

### 템플릿·색
- 돌잔치 전용 10종: 파스텔 색(피치·민트·레몬·하늘·라벤더·코랄·크림·세이지·로즈·스카이), 둥근 서체, 표지 사진 틀(아치·원형·타원·둥근 사각·구름), 반짝이(별·하트·점·없음).
- [색상] 칩은 돌잔치용 10색을 보여 준다.
- 둥근 서체는 Google Fonts 의 한글 서체를 `npx expo install` 로 추가한다(예: 고운돋움). 라이선스는 OFL.

## 6. 참석 여부·참석 신청 (기업·모임 공통)

- 받는 항목(테마별 기본, 끌 수 없음)
  - 모임: 이름, 참석/불참, 동반 인원(0~9)
  - 기업: 이름, 소속, 연락처, 참석/불참
- 하객: 폼을 내면 "응답을 보냈어요". 같은 기기에서 다시 열면 낸 내용을 보여 주고 고칠 수 있다(기기 저장). 마감일이 지나면 폼 대신 "마감되었어요".
- 만든 사람: 나의 초대장 카드에 [참석 응답 (N)] 버튼 → 응답 명단 화면
  - 합계(참석 인원·불참)
  - **행 추가·수정·삭제**: 전화 등으로 받은 응답을 직접 넣고 고친다. 직접 넣은 행은 "직접 입력" 표시.
  - 새 응답이 오면 알림(기존 알림 목록).
- 저장: 지금처럼 mock 서비스(`services/mock`)에 초대장별로 저장한다. 서버가 생기면 같은 인터페이스로 바꾼다.
- 확인됨(2026-10-25): "만든 사람이 행 추가해서 관리"는 명단에 응답 행을 직접 추가하는 뜻이 맞다.

## 7. 공통 사항

- **템플릿 미리보기 예시**: 테마마다 예시 초대장(문구·이름·일정)을 채우고 AI 실사 사진을 넣는다.
  - 돌잔치 약 10장(아기·돌상·가족), 기업 약 6장(행사장·연사 얼굴 3), 모임 약 6장.
  - 무료 모델(Z Image), 긴 변 1080px JPEG, 실존 인물 아님. 예시 사진은 미리보기에만 쓴다.
- **직접 꾸미기 정보 글자**: 테마별로 바뀐다(돌잔치: 아이 이름·나이·날짜·장소·보호자 / 기업: 행사명·주최·일시·장소 / 모임: 모임 이름·주최·일시·장소).
- **다국어**: 새 문구는 모두 영어 사전에 넣는다(누락 검사 테스트가 막는다). 사용자 글은 번역하지 않는다.
- **레터·활성화 정책**: 결혼식과 같다(테마마다 다르게 하지 않음).
- **홈·만들기 화면**: 테마 카드를 누르면 지금처럼 그 테마 템플릿 목록. 돌잔치·기업·모임 템플릿 미리보기가 실제 초대장 화면(스토리형·스크롤형)으로 바뀐다.

## 8. 이번에 하지 않는 것

- 돌잔치: 인터뷰, 안내사항, 연락처, RSVP, D+Day, 하객 앨범, 화환, 중간 사진, 오프닝 애니메이션
- 참석 응답: 질문 직접 추가, 엑셀 내려받기, 카카오 알림톡
- 테마 간 바꾸기(결혼식으로 만든 걸 돌잔치로 바꾸기)
- 서버 저장(지금은 기기 저장 mock)

## 9. 오류·예외

- 필수 칸이 비면 그 섹션 독바에 빨간 점, 최종저장 때 첫 빈 섹션 시트를 연다(결혼식과 같음).
- 성장 이야기·일정표 등 목록이 최대 개수면 [+ 추가] 버튼을 끄고 "최대 ○개까지" 안내.
- 태어난 날이 행사일보다 뒤면 "태어난 날을 확인해 주세요."
- 참석 응답 폼: 이름 비면 "이름을 입력해 주세요.", 기업 연락처 형식 검사.
- 알 수 없는 테마 id 의 초대장은 "지원하지 않는 초대장이에요."(앱이 멈추지 않게).

## 10. 테스트

- 테마 정의별: 기본 콘텐츠·검사 함수·페이지 순서·입력항목 기본값 단위 테스트
- 결혼식 회귀: 기존 테스트 전부 그대로 통과 + 저장된 결혼식 초대장(옛 데이터) 불러오기 테스트
- 성장 이야기 미리 채우기(100일 계산, 이미 고친 항목 보존)
- 참석 응답: 제출·수정·마감·직접 행 추가·합계
- 번역 누락 검사
- 브라우저 QA: 테마마다 미리보기 → 만들기 → 저장 → 하객 화면, 스토리형·스크롤형, 412·1280 폭

## 11. 단계

1. 공통 구조(테마 정의로 옮기기, 결혼식 동작 그대로) + 목록형 입력 부품
2. 돌잔치 (템플릿·서체·예시 사진 포함)
3. 기업 행사 + 참석 응답(공통)
4. 모임

각 단계 끝에 사용자 확인을 받고 다음 단계로 간다.
