# 마이페이지 설계

설계 화면 13장(마이페이지·알림 풀 모달·회원정보·회원정보 수정·회원탈퇴·My 레터(충전/충전내역/사용내역/이용안내)·앱 설정·WUZU 정보·공지사항·약관)을 기준으로 한다.
`2026-10-20-my-invitations-and-letters-design.md`(레터·인앱 충전) 위에 얹는다. 서버 없음 — mock 서비스.

## 0. 이전 설계와 바뀌는 점 (새 화면 기준)
- **충전 상품**: 레터 10 ₩1,000 / 50 ₩5,000 / 100 ₩10,000 / 300 ₩30,000 / 500 ₩50,000 (1레터 = 100원, 보너스 없음). 이전 기본안(50/110/330/550)을 대체한다.
- **레터 지갑(`/wallet`) = My 레터**: 이전 계획 Task 5(지갑 화면)는 만들지 않고 이 설계의 My 레터로 대신한다. 경로 `/wallet`은 그대로(헤더 레터 배지·레터 부족 모달이 이미 이 경로로 감).
- 마이페이지 탭의 현재 화면(내 정보·설정 요약)은 이 설계로 바꾼다.

## 1. 마이페이지 (`(tabs)/mypage`)
- 헤더 "마이페이지" + 오른쪽 🔔(알림 풀 모달). 안 읽은 알림이 있으면 점 표시.
- 상단: "{닉네임}님 반가워요." / "보유중인 레터 N 레터"(누르면 My 레터 [레터충전] 탭).
- 메뉴(줄 목록): 회원정보 / My 레터 / 앱 설정 / WUZU 정보 / 로그아웃(회색 줄, 누르면 로그아웃 후 홈).
- 하단 사업자 정보 영역: 링크 [이용약관 | 유료 이용약관 | 개인정보 처리방침 | 구매 복원] + 회사명·사업자 정보(`src/config`의 `BUSINESS_INFO`).
- 비로그인: 로그인 화면(기존).

## 2. WUZU 알림 (풀 모달 `/notifications`)
- 헤더 "WUZU 알림" + ✕(닫기). 탭: 전체 / 공지 / 구매 (커뮤니티는 1차 제외 — 숨김).
- 안내: "알림은 수신일로부터 15일 동안 보관됩니다. 수신 거부 : 마이페이지 > 앱 설정"
- 항목: 카테고리 아이콘(공지 🔔 / 구매 ₩, 어두운 원), 날짜 `YYYY.MM.DD`, 제목·내용, [바로가기 >](알림에 연결된 화면으로).
- 최신순, 15일 지난 알림은 보이지 않음. 비면 "받은 알림이 없습니다."
- 알림 생성(mock):
  - 구매: 레터 사용·충전 시 자동 — "[구매] 초대장No. {번호}" / "'{이름}' 초대장 활성화 - 50레터 사용", 충전은 "[구매] 레터 충전" / "레터 500 충전 - 50,000원". 바로가기 → 사용은 나의 초대장, 충전은 My 레터 [충전내역].
  - 공지: 공지사항 데이터에서 — "[공지] {제목}", 바로가기 → 공지사항 상세.
- 모달을 열면 모두 읽음 처리(배지 점 사라짐).

## 3. 회원정보 (`/account`)
- 카드: 아이디 / 닉네임 / 성별 / 생년월일 (없으면 `-`).
  - 아이디: 이메일 가입은 이메일, 간편 로그인은 자동 생성 아이디(`ka_` + 8자, 카카오). 수정 불가.
- "회원정보 · 최종 수정일 : YYYY-MM-DD" + [수정하기] → 회원정보 수정.
- "마케팅 정보 수신 동의" 토글 + "최종 수정일 : YYYY-MM-DD". 끄면 앱 설정의 PUSH 알림도 꺼진다. 켜면 PUSH 알림도 켜진다.
- 사용자 필드 추가: `loginId`, `profileUpdatedAt`, `marketingUpdatedAt`.

## 4. 회원정보 수정 (`/account/edit`)
- 아이디(읽기 전용) / 닉네임* / 생년월일 [날짜 선택] [☑ 사용] / 성별 [남성▾] [☑ 사용].
- 닉네임: 한글·영어·숫자 2~10자(공백·기호 불가). 오류 "한글, 영어, 숫자 2~10자로 입력해 주세요."
- 사용 체크 해제 시 입력칸 비활성(회색)·값 저장 안 함(`-`). 체크 시 그 항목 필수(비면 [회원정보 수정] 시 오류).
- 생년월일은 기존 날짜 선택기(편집기 `Pickers.tsx`) 재사용, 오늘 이후 불가.
- [이전] → 회원정보 / [회원정보 수정] → 검사 통과 시 저장 + "수정이 완료되었습니다." 토스트 → 회원정보.
- 하단 [회원탈퇴] 링크 → 회원탈퇴.

## 5. 회원탈퇴 (`/account/withdraw`, 완료 `/account/withdrawn`)
- "정말 회원 탈퇴를 하시겠습니까?" + 안내 두 묶음(탈퇴신청 후 30일 이내 / 31일 초과) — 설계 화면 문구를 쓰되 기간은 기존 철회 기간 30일로(사용자 확정).
- [☐ 회원탈퇴 약관을 확인하였습니다.] 체크해야 [탈퇴하기] 활성.
- [탈퇴하기] → 탈퇴 신청(`status: 'withdrawing'`, `withdrawRequestedAt`) → 로그아웃 → 완료 화면: wuzu 워드마크 + "회원 탈퇴 처리 되었습니다." / "그동안 WUZU를 이용해주셔서 감사합니다." / [확인] → 홈.
- 30일 안에 다시 로그인하면 기존 철회 모달(`AccountStatusModals`)이 뜬다(기존 30일 유지).
- 간편 로그인 아이디 자동 부여는 어드민·DB 관리용으로 필요(사용자 확정). 이메일 가입은 이메일이 아이디.

## 6. My 레터 (`/wallet`)
- 헤더 "My 레터" + ←. 탭: 레터충전 / 충전내역 / 사용내역(라우트 파라미터 `tab`으로 시작 탭 지정).
- 공통: 보유 레터 바(다크 블록), 하단 "최근 1년까지의 내역만 제공합니다."(내역 탭), 맨 아래 [이용안내 ▾] 펼치기/접기.
- 레터충전: 상품 5개 줄(레터 N / 가격 배지) → 인앱 결제 시트(이전 설계와 같음) → 성공 시 레터 증가·알림 생성·"레터 N개가 충전되었어요."
- 충전내역: 카드(결제일 `YYYY.MM.DD`, "레터 충전", `+N`, `금액원`). 1년 이내만. 비면 "최근 1년간 충전하신 내역이 없습니다."
- 사용내역: 카드(사용일, `초대장 No. {번호}`, `'{이름}' 초대장 활성화 / 기간 연장 N일 / 컨텐츠 정보 수정`, `-N`). 활성화와 연장을 함께 산 건은 한 장(`'{이름}' 초대장 활성화 + 기간 연장 N일`). 1년 이내만. 비면 "최근 1년간 사용하신 내역이 없습니다."
  - 스티커 구매 항목은 스티커 기능이 생길 때 추가(1차 제외).
- 이용안내: iOS·웹은 App Store 문구, 안드로이드는 Google Play 문구(설계 화면 두 버전 그대로).
- 기록에 결제 금액(원) 필드 추가: `LedgerEntry.priceWon?`(충전만).

## 7. 앱 설정 (`/settings`)
- "PUSH 알림 · 공지사항, 이벤트, 구매 알림" 토글. 세션의 `pushConsent`와 연결.
- 규칙: 마케팅 동의를 켜면 PUSH 자동 ON. PUSH를 꺼도 마케팅 동의는 그대로. 마케팅 동의를 끄면 PUSH도 OFF.

- 공지사항(`/about/notices`): [전체▾] 구분 필터(바텀시트: 전체/서비스/프로모션/업데이트/기타) → 목록(제목 `[구분]`·날짜) → 상세(`/about/notices/[id]`: 제목·날짜·본문).
