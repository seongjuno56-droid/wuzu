# 다국어(한국어·영어) 설계 — 2026-10-21

사용자 요청: "주 타겟은 해외 유저 — 언어 선택 + 번역". 사용자가 자는 동안 진행(질문 없이 실행 지시)이라 결정은 아래에 기록하고 내일 확인받는다.

## 결정
- 언어: 한국어(ko)·영어(en). 구조는 언어를 더할 수 있게(사전 파일 추가) 만든다.
- 기본 언어: 처음 실행 시 기기 언어(한국어면 ko, 그 밖은 en). 선택은 기기에 저장.
- 바꾸는 곳: 홈 상단 🌐 버튼(로그인 전에도), 마이페이지 > 앱 설정 "Language / 언어".
- 방식: **한국어 원문을 키로** 쓴다. 공통 글자 컴포넌트(Txt·초대장 IText·입력칸 안내 문구·하단 탭 제목)가 그릴 때 번역 → 화면 코드는 한국어 그대로, 언어를 바꾸면 즉시 반영.
  - `{0}` 자리 표시가 있는 키는 패턴 — 동적 문장(숫자·이름이 낀 문장)도 번역, 낀 값(요일·공지 제목)도 다시 번역 시도.
  - 사전에 없는 글자(사용자 입력: 이름·인사말·캔버스 텍스트)는 그대로.
  - 캔버스: 연결 텍스트(날짜·요일·안내 글자)만 번역, 직접 쓴 텍스트는 그대로.
- 시간 서식: 영어는 `2 PM` / `2:30 PM`.
- 누락 방지: `scripts/extract-ko.js`가 코드 속 한국어 화면 문구를 모으고, `src/i18n/__tests__/i18n.test.ts`가 영어 사전에 모두 있는지 검사(새 문구를 쓰면 테스트가 알려줌).

## 한계·다음 단계
- 접근성 라벨은 Txt 의 것만 번역(버튼 등 Pressable 의 accessibilityLabel 은 한국어).
- 하객 보기 언어 = 보는 사람의 앱 언어(웹은 기기 언어). 초대장마다 언어를 고르는 기능은 다음 단계.
- 템플릿 예시 이름(홍길동 등)·주소 등 고유명사는 번역하지 않는다.
- 일본어·중국어 등은 사전 파일만 추가하면 된다(번역 품질 검수 필요).
- 홈 배너 "첫 초대장은 무료", "수정은 횟수 제한 없이"는 레터 정책과 맞지 않음 — 문구 결정 필요(사용자 확인 대기).
