# 마이페이지 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 마이페이지(인사·보유 레터·메뉴), WUZU 알림 풀 모달, 회원정보 보기/수정/탈퇴, My 레터(충전·충전내역·사용내역·이용안내), 앱 설정(PUSH), WUZU 정보(버전·공지사항·약관)를 만든다.

**Architecture:** 규칙은 순수 함수(`src/features/account/rules.ts`, `src/features/notifications/model.ts`, `src/features/wallet/history.ts`)로 두고 테스트한다. 인증 mock에 계정 수정·마케팅·탈퇴 신청을 더하고, 알림은 별도 mock 서비스(AsyncStorage)로 지갑 구매·충전 때 함께 기록한다. 화면은 기존 컴포넌트(Header, Screen, AppModal, SelectSheet, SegmentedTabs, HomeFooter, PaymentSheetHost)를 재사용한다.

**Tech Stack:** Expo SDK 57, expo-router, TypeScript, Zustand, AsyncStorage, expo-constants, jest-expo.

**Spec:** `docs/superpowers/specs/2026-10-20-mypage-design.md` (선행: `docs/superpowers/specs/2026-10-20-my-invitations-and-letters-design.md`, 계획 `docs/superpowers/plans/2026-10-20-my-invitations-and-letters.md` Task 1~4·6~11)

## Global Constraints

- 영어 필수 표기 외 사용자 문구·주석·커밋 메시지는 한국어. 커밋 끝 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `npx expo install`만, Expo Go 포함 모듈만. 라우트는 `src/app/`에만. 화해 스타일 토큰, 분홍 강조색 쓰지 않음.
- 충전 상품: 레터 10 ₩1,000 / 50 ₩5,000 / 100 ₩10,000 / 300 ₩30,000 / 500 ₩50,000, 보너스 없음.
- 닉네임(회원정보 수정): 한글·영어·숫자 2~10자.
- 탈퇴 철회 기간 30일(기존 유지). 간편 로그인 아이디 자동 부여(카카오 `ka_` + 8자), 이메일 가입은 이메일이 아이디.
- 알림 보관 15일, 최신순, 탭 전체/공지/구매(커뮤니티 숨김), 날짜 `YYYY.MM.DD`.
- 충전·사용 내역은 최근 1년만, 하단 "최근 1년까지의 내역만 제공합니다."
- 마케팅 동의 ON → PUSH ON / 마케팅 동의 OFF → PUSH OFF / PUSH OFF → 마케팅 동의 그대로.
- 버전은 `app.json`의 `expo.version`, 누르면 `STORE_URLS`(src/config.ts) 열기.
- 개발 서버는 이미 켜져 있음(켜거나 끄지 않는다). 완료 전 `npx tsc --noEmit`, `npx jest`.

## Review Focus

1. **예전 계정에 아이디가 없음** — 시드·기존 가입자에게 `loginId`가 없어도 회원정보에 아이디가 보여야 한다(Task 1 보정 테스트).

3. **알림 15일 경계** — 정확히 15일 전 알림은 보이지 않는다(Task 3 `visibleNotifications` 테스트).
4. **1년 내역 경계** — 365일 지난 기록은 내역에 안 보인다(Task 2 `withinYear` 테스트).
5. **탈퇴 후 바로 재로그인** — 탈퇴 직후 같은 계정으로 로그인하면 철회 모달이 뜬다(Task 1 서비스 테스트, Task 9 QA).

```ts
/**
 * 계정 규칙 — 닉네임, 회원정보 수정 검사, 아이디
 * (설계: docs/superpowers/specs/2026-10-20-mypage-design.md)
 */
import { isValidBirth } from '../../lib/format';
import type { Gender, User } from '../../services/types';

const NICKNAME_RE = /^[가-힣a-zA-Z0-9]{2,10}$/;

/** 회원정보 수정 닉네임: 한글·영어·숫자 2~10자 */
export const isValidNickname = (s: string) => NICKNAME_RE.test(s.trim());

export interface AccountEditInput {
  name: string;
  birth: string;
  useBirth: boolean;
  gender: Gender | '';
  useGender: boolean;
}

/** 오류 항목 목록 (빈 배열 = 통과). 사용 체크를 끈 항목은 검사하지 않는다 */
export function validateAccountEdit(i: AccountEditInput): ('name' | 'birth' | 'gender')[] {
  const errors: ('name' | 'birth' | 'gender')[] = [];
  if (!isValidNickname(i.name)) errors.push('name');
  if (i.useBirth && !isValidBirth(i.birth)) errors.push('birth');
  if (i.useGender && !i.gender) errors.push('gender');
  return errors;
}

/** 저장할 값: 사용 체크를 끈 항목은 비운다 */
export function toAccountValues(i: AccountEditInput): { name: string; birth?: string; gender?: Gender } {
  return {
    name: i.name.trim(),
    birth: i.useBirth ? i.birth : undefined,
    gender: i.useGender && i.gender ? i.gender : undefined,
  };
}

const ID_CHARS = 'abcdefghijklmnopqrstuvwxyz0123456789';

/** 간편 로그인(카카오) 아이디: ka_ + 영소문자·숫자 8자 (어드민·DB 관리용) */
export function socialLoginId(random: () => number = Math.random): string {
  let id = '';
  for (let i = 0; i < 8; i++) id += ID_CHARS[Math.floor(random() * ID_CHARS.length) % ID_CHARS.length];
  return `ka_${id}`;
}

/** 화면 표시용 아이디 */
export const displayLoginId = (u: Pick<User, 'loginId' | 'email'>) => u.loginId ?? u.email ?? '-';
```

const newestFirst = (a: LedgerEntry, b: LedgerEntry) => b.createdAt.localeCompare(a.createdAt);

const extendDays = (e: LedgerEntry) => {
  const line = e.lines.find((l) => l.label.startsWith('이용 기간 연장'));
  return line ? Number(line.label.replace(/\D/g, '')) : 0;
};

  const days = extendDays(e);
  switch (e.kind) {
    case 'activate':
      return `${name} 초대장 활성화${days ? ` + 기간 연장 ${days}일` : ''}`;
    case 'extend':
      return `${name} 기간 연장 ${days}일`;
    case 'edit':
      return `${name} 컨텐츠 정보 수정`;

/** WUZU 알림 규칙 — 15일 보관, 최신순, 탭(전체/공지/구매) */
import type { Notice } from '../../data/notices';
import type { AppNotification, LedgerEntry } from '../../services/types';
import { usageText } from '../wallet/history';

export const KEEP_DAYS = 15;
export type NotificationTab = 'all' | 'notice' | 'purchase';

export function visibleNotifications<T extends Pick<AppNotification, 'category' | 'createdAt'>>(
  list: T[],
  tab: NotificationTab,
  now: Date,
): T[] {
  const limit = now.getTime() - KEEP_DAYS * 86400000;
  return list
    .map((n, i) => ({ n, i }))
    .filter(({ n }) => Date.parse(n.createdAt) > limit && (tab === 'all' || n.category === tab))
    // 최신순, 같은 시각이면 나중에 추가된 것 먼저
    .sort((a, b) => b.n.createdAt.localeCompare(a.n.createdAt) || b.i - a.i)
    .map(({ n }) => n);
}

export const noticeNotifications = (notices: Notice[]): AppNotification[] =>
  notices.map((n) => ({
    id: `notice-${n.id}`,
    userId: null,
    category: 'notice',
    title: `[공지] ${n.title}`,
    body: '',
    link: `/about/notices/${n.id}`,
    createdAt: n.date,
  }));

const won = (n: number) => `${n.toLocaleString('ko-KR')}원`;

/** 레터 사용·충전 기록 → 구매 알림 */
export function purchaseNotification(e: LedgerEntry): Omit<AppNotification, 'id'> {
  if (e.kind === 'charge') {
    return {
      userId: e.userId,
      category: 'purchase',
      title: '[구매] 레터 충전',
      body: `레터 ${e.total} 충전 - ${won(e.priceWon ?? 0)}`,
      link: '/wallet?tab=charges',
      createdAt: e.createdAt,
    };
  }
  return {
    userId: e.userId,
    category: 'purchase',
    title: `[구매] 초대장No. ${e.number}`,
    body: `${usageText(e)} - ${-e.total}레터 사용`,
    link: '/my-invites',
    createdAt: e.createdAt,
  };
}

interface Db {

export function createMockNotificationService(opts: { delayMs: number; storage: KeyValueStorage; now?: () => Date }): NotificationService {
  const { delayMs, storage } = opts;
  const clock = opts.now ?? (() => new Date());
  const wait = () => new Promise((r) => setTimeout(r, delayMs));
  const load = async (): Promise<Db> => {
    const raw = await storage.getItem(KEY);
    return raw ? JSON.parse(raw) : { items: [], readAt: {} };
  };
  const save = (db: Db) => storage.setItem(KEY, JSON.stringify(db));

  const mine = (db: Db, userId: string, now: Date) =>
    visibleNotifications(
      [...noticeNotifications(noticeList(now)), ...db.items.filter((n) => n.userId === userId)],
      'all',

  return {
    async list(userId, now = clock()) {
      await wait();
      return mine(await load(), userId, now);
    },
    async add(n) {
      const db = await load();
      db.items.push({ ...n, id: `nt-${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 6)}` });
      await save(db);
    },

    },
    async markAllRead(userId, at) {
      const db = await load();
      db.readAt[userId] = at;

    },

import { Redirect, router } from 'expo-router';
import { useState } from 'react';
import { Pressable, StyleSheet, View } from 'react-native';

import { AccountEditInput, displayLoginId, toAccountValues, validateAccountEdit } from '../../features/account/rules';
import { Check } from '../../features/invitation/editor/fields';
import { formatBirthInput } from '../../lib/format';
import { authService, Gender } from '../../services';
import { useSession } from '../../store/session';
import { colors, spacing } from '../../theme';

/** 회원정보 수정: 닉네임*(2~10) / 생년월일·성별(사용 체크 시 필수) */
export default function AccountEditScreen() {
  const user = useSession((s) => s.user);
  const setUser = useSession((s) => s.setUser);
  const [form, setForm] = useState<AccountEditInput>(() => ({
    name: user?.name ?? '',
    birth: user?.birth ?? '',
    useBirth: !!user?.birth,
    gender: user?.gender && user.gender !== 'none' ? user.gender : '',
    useGender: !!user?.gender && user.gender !== 'none',
  }));
  const [touched, setTouched] = useState(false);
  const [saving, setSaving] = useState(false);
  if (!user) return <Redirect href="/auth/login" />;

  const errors = validateAccountEdit(form);
  const set = (patch: Partial<AccountEditInput>) => setForm((f) => ({ ...f, ...patch }));

  const submit = async () => {
    setTouched(true);
    if (errors.length || saving) return;
    setSaving(true);
    try {
      setUser(await authService.updateAccount(user.id, toAccountValues(form)));
      toast('수정이 완료되었습니다.');
      router.back();
    } catch {
      toast('수정하지 못했어요. 잠시 후 다시 시도해 주세요.');
    } finally {
      setSaving(false);
    }
  };

  const err = (k: 'name' | 'birth' | 'gender', text: string) =>
    touched && errors.includes(k) ? { type: 'error' as const, text } : null;

  return (
    <Screen header={<Header title="회원정보 수정" />} contentStyle={styles.content}>
      <View style={styles.field}>
        <Txt weight="semibold">아이디</Txt>
        <Txt color={colors.muted}>{displayLoginId(user)}</Txt>
      </View>
      <TextField
        label="닉네임"
        required
        value={form.name}
        onChangeText={(name) => set({ name })}
        maxLength={10}
        message={err('name', '한글, 영어, 숫자 2~10자로 입력해 주세요.')}
      />
      <View style={styles.field}>
        <Txt weight="semibold">생년월일</Txt>
        <View style={styles.row}>
          <View style={[styles.flex, !form.useBirth && styles.off]} pointerEvents={form.useBirth ? 'auto' : 'none'}>
            <TextField
              placeholder="1991-01-01"
              value={form.birth}
              onChangeText={(v) => set({ birth: formatBirthInput(v) })}
              keyboardType="number-pad"
              maxLength={10}
              message={err('birth', '올바른 생년월일을 입력해 주세요.')}
            />
          </View>
          <Check label="사용" value={form.useBirth} onChange={(useBirth) => set({ useBirth })} />
        </View>
      </View>
      <View style={styles.field}>
        <Txt weight="semibold">성별</Txt>
        <View style={styles.row}>
          <View style={[styles.flex, !form.useGender && styles.off]} pointerEvents={form.useGender ? 'auto' : 'none'}>
            <OptionGroup<Gender | ''>
              value={form.gender}
              onChange={(gender) => set({ gender })}
              options={[
                { value: 'male', label: '남성' },
                { value: 'female', label: '여성' },
              ]}
            />
          </View>
          <Check label="사용" value={form.useGender} onChange={(useGender) => set({ useGender })} />
        </View>
        {touched && errors.includes('gender') && (
          <Txt variant="caption" color={colors.danger}>
            성별을 선택해 주세요.
          </Txt>
        )}
      </View>
      <View style={styles.row}>
        <Button label="이전" variant="outline" onPress={() => router.back()} style={styles.flex} />
        <Button label={saving ? '저장 중…' : '회원정보 수정'} onPress={submit} style={styles.flex} />
      </View>
      <Pressable onPress={() => router.push('/account/withdraw')} style={styles.withdraw} accessibilityRole="button">
        <Txt variant="caption" color={colors.muted} style={styles.underline}>
          회원탈퇴
        </Txt>
      </Pressable>
    </Screen>
  );
}

const styles = StyleSheet.create({
  flex: { flex: 1 },
  content: { padding: spacing.xl, gap: spacing.xl },
  field: { gap: spacing.sm },
  row: { flexDirection: 'row', alignItems: 'center', gap: spacing.md },
  off: { opacity: 0.4 },
  withdraw: { alignSelf: 'center', padding: spacing.sm },
  underline: { textDecorationLine: 'underline' },
});

  const user = useSession((s) => s.user);
  const balance = useWallet((s) => s.balance);

  const [tab, setTab] = useState<Tab>(params.tab ?? 'charge');

    useCallback(() => {
      load();
    }, [load]),
  );

    if (buying) return;
    setBuying(productId);

      const result = await paymentService.purchase(productId);
      if (result === 'success') {
        const next = await walletService.charge(user.id, productId);

        toast(`레터 ${LETTER_PRODUCTS.find((p) => p.id === productId)!.letters}개가 충전되었어요.`);

        toast('결제에 실패했어요. 잠시 후 다시 시도해 주세요.');
      }
    } finally {
      setBuying(null);
    }
  };

  const list = ledger ? (tab === 'charges' ? chargeEntries(ledger, now) : spendEntries(ledger, now)) : null;

      header={<Header title="My 레터" />}

      footer={
        <View>
          <Pressable onPress={() => setGuide((g) => !g)} style={styles.guideBar} accessibilityRole="button" accessibilityState={{ expanded: guide }}>
            <Txt variant="caption" color={colors.label}>
              이용안내
            </Txt>
            <Ionicons name={guide ? 'caret-up' : 'caret-down'} size={12} color={colors.label} />
          </Pressable>
          {guide && (
            <View style={styles.guide}>
              {usageGuide().map((t) => (
                <Txt key={t} variant="tiny" color={colors.label}>
                  • {t}
                </Txt>
              ))}
            </View>
          )}
        </View>
      }
    >
      <SegmentedTabs
        value={tab}
        onChange={setTab}
        options={[
          { value: 'charge', label: '레터충전' },
          { value: 'charges', label: '충전내역' },
          { value: 'usage', label: '사용내역' },
        ]}
      />
      <View style={styles.balance}>
        <Txt weight="semibold" color={colors.canvas} style={styles.flex}>
          보유 레터
        </Txt>
        <Txt weight="semibold" color={colors.canvas}>
          {balance ?? '–'}
        </Txt>
      </View>

      {tab === 'charge' ? (
        <>
          <Txt variant="caption" color={colors.label}>
            레터 충전
          </Txt>
          {LETTER_PRODUCTS.map((p) => (
            <Pressable
              key={p.id}
              onPress={() => charge(p.id)}
              style={({ pressed }) => [styles.product, pressed && styles.pressed]}
              accessibilityRole="button"
              accessibilityLabel={`레터 ${p.letters} ${won(p.price)}`}
            >
              <Txt style={styles.flex}>레터 {p.letters}</Txt>
              {buying === p.id ? (
                <ActivityIndicator color={colors.inkSoft} />
              ) : (
                <View style={styles.price}>
                  <Txt variant="caption" weight="semibold" color={colors.canvas}>
                    {won(p.price)}
                  </Txt>
                </View>
              )}
            </Pressable>
          ))}
        </>
      ) : (
        <>
          <Txt variant="caption" color={colors.label}>
            {tab === 'charges' ? '레터 충전' : '사용내역'}
          </Txt>
          {list === null ? (
            <ActivityIndicator color={colors.inkSoft} />
          ) : list.length === 0 ? (
            <Txt color={colors.muted} align="center" style={styles.empty}>
              {tab === 'charges' ? '최근 1년간 충전하신 내역이 없습니다.' : '최근 1년간 사용하신 내역이 없습니다.'}
            </Txt>
          ) : (
            list.map((e) => (
              <View key={e.id} style={styles.card}>
                <View style={styles.flex}>
                  <Txt variant="caption" color={colors.muted}>
                    {formatDate(e.createdAt)}
                  </Txt>
                  {tab === 'usage' && (
                    <Txt variant="caption" color={colors.muted}>
                      이력No. {e.number}
                    </Txt>
                  )}
                  <Txt weight="semibold">{tab === 'charges' ? '레터 충전' : usageText(e)}</Txt>
                </View>
                <View style={styles.amount}>
                  <Txt weight="semibold" color={tab === 'charges' ? colors.infoInk : colors.danger}>

                    <Txt variant="caption">{e.priceWon.toLocaleString('ko-KR')}원</Txt>
                  )}
                </View>
              </View>
            ))
          )}
          <Txt variant="caption" color={colors.muted} align="center" style={styles.note}>
            최근 1년까지의 내역만 제공합니다.
          </Txt>
        </>

  );
}

/** 공지사항: 구분 필터 + 목록(제목·작성일) */
export default function NoticesScreen() {
  const [filter, setFilter] = useState<NoticeCategory | 'all'>('all');
  const [open, setOpen] = useState(false);
  const list = useMemo(() => noticeList().filter((n) => filter === 'all' || n.category === filter), [filter]);

  return (
    <Screen header={<Header title="공지사항" />} contentStyle={styles.content}>
      <Pressable onPress={() => setOpen(true)} style={styles.filter} accessibilityRole="button">
        <Txt variant="caption" color={colors.label}>
          {OPTIONS.find((o) => o.value === filter)!.label}
        </Txt>
        <Ionicons name="caret-down" size={12} color={colors.label} />
      </Pressable>
      {list.length === 0 ? (
        <Txt color={colors.muted} align="center" style={styles.empty}>
          등록된 공지사항이 없습니다.
        </Txt>
      ) : (
        list.map((n) => (
          <Pressable key={n.id} onPress={() => router.push(`/about/notices/${n.id}`)} style={styles.item} accessibilityRole="button">
            <Txt variant="subtitle" weight="semibold">
              [{NOTICE_CATEGORY_LABEL[n.category]}] {n.title}
            </Txt>
            <Txt variant="caption" color={colors.muted}>
              {formatDate(n.date)}
            </Txt>
          </Pressable>
        ))
      )}
      <SelectSheet<NoticeCategory | 'all'>
        visible={open}
        title="구분"
        options={OPTIONS}
        value={filter}
        onClose={() => setOpen(false)}
        onSelect={(v) => {
          setFilter(v);
          setOpen(false);
        }}
      />
    </Screen>
  );
}
