# 모임 초대장 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 생일·동창회·집들이·송년회 같은 모임 초대장을 결혼식·돌잔치·기업과 같은 수준(템플릿 미리보기 → 입력항목 선택 → 정보 입력 → 저장·활성화 → 하객 화면)으로 만든다.

**Architecture:** 테마 정의에 `meetup` 을 등록한다. 3단계에서 만든 부품을 최대한 다시 쓴다.
- 일정표는 기업 프로그램과 같은 섹션 키(`program`)·항목 타입(`ProgramItem`)·폼·장을 쓰고 라벨만 '일정표'.
- 참석 여부는 기업 참석 신청과 같은 키(`rsvp`)·서비스·모달·명단 화면을 쓴다. 받는 항목은 이미 `rsvpFields('meetup')` 가 이름·참석/불참·동반 인원으로 정해 두었다.
- 기본 정보 필드 이름은 기업과 같게(`eventName`·`host`) 두어 표지 정보 글자(`eventName`·`host`)를 그대로 쓴다.
- 새로 만드는 것은 안내사항(`notices`) 장, 회비 계좌(`account` 키, 모임 전용 모양), 모임 템플릿·표지·예시뿐이다.

**Tech Stack:** Expo SDK 57, expo-router, React Native + react-native-web, TypeScript, Zustand, AsyncStorage, Jest(jest-expo), react-test-renderer(`src/test/ui.ts` 도우미).

**Spec:** `docs/superpowers/specs/2026-10-22-dol-corporate-meetup-themes-design.md` (5·6·7·9·10장, 11장의 4단계)

## 사용자 확인이 필요한 판단 (계획 검토 때)

- **모임 카드의 참석 응답 버튼 위치**: 모임은 방명록과 참석 여부를 둘 다 쓴다. 카드 버튼 줄은 이미 꽉 차 있어서, 방명록 버튼은 그대로 두고 [⋮ 더보기] 시트에 '참석 응답 (N)'을 넣는다(기업은 지금처럼 카드에 버튼). 버튼 줄에 하나 더 넣기를 원하면 알려 달라.
- **표지 사진이 없을 때**: 표지 배치는 사진 자리를 비워 둔 채로 글자가 그 아래에 있다. 사진 없이 쓰는 사람이 많다면 글자를 가운데로 올리는 배치를 따로 둘 수 있다(이번에는 하지 않음).

export function defaultMeetupContent(today: Date = new Date()): MeetupContent {
  const w = defaultContent(today);
  return {

const filled = (s: string) => s.trim().length > 0;
const within = (s: string, max: number) => s.trim().length <= max;

export function validateMeetup(key: SectionKey, c: MeetupContent): string[] {
  const errors: string[] = [];
  const check = (ok: boolean, field: string) => !ok && errors.push(field);
  switch (key) {
    case 'basic':
      check(filled(c.basic.eventName) && within(c.basic.eventName, MEETUP_LIMITS.eventName), 'eventName');
      check(within(c.basic.host, MEETUP_LIMITS.host), 'host');
      return errors;
    case 'notices': {
      const items = c.notices.items;
      check(
        items.length >= 1 &&
          items.length <= MEETUP_LIMITS.notices &&
          items.every(
            (n) =>
              filled(n.title) && within(n.title, MEETUP_LIMITS.noticeTitle) && within(n.text, MEETUP_LIMITS.noticeText),
          ),
        'items',
      );
      return errors;
    }
    case 'account': {
      const a = c.account;
      check(within(a.amount, MEETUP_LIMITS.amount), 'amount');
      check(filled(a.bank) && within(a.bank, MEETUP_LIMITS.bank), 'bank');
      check(filled(a.number) && within(a.number, MEETUP_LIMITS.number), 'number');
      check(filled(a.holder) && within(a.holder, MEETUP_LIMITS.holder), 'holder');
      return errors;
    }
    case 'program':
    case 'rsvp':
      // 일정표·참석 여부는 기업과 같은 규칙
      return validateCorporate(key, { program: c.program, rsvp: c.rsvp, ceremony: c.ceremony } as CorporateContent);
    default:
      // 일시·장소·초대 문구·갤러리·방명록·엔딩·BGM 은 결혼식과 같은 규칙
      return validateSection(key, {
        ...defaultContent(),
        ceremony: c.ceremony,
        greeting: c.greeting,
        gallery: c.gallery,
        guestbook: c.guestbook,
        ending: c.ending,
        bgm: c.bgm,
      });
  }
}
